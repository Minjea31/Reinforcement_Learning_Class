# 학습 기록

2026-11-27: 첫 PPO·A2C·SAC 비교를 종료하고 모델·로그·영상·그래프·수정 전 코드를 `models/first_trial/`에 보존했다. 보상·중단 이유·모델별 최종 스텝은 그 안의 `README.md`, 최종 그래프는 `graph/{ppo,a2c,sac}/`에 있다.

수정 v4는 보상·관측 타이머·성공 통계를 일치시키고, 물리 스텝 뒤 이전 보상을 중복 계산하는 경로를 없앴다. 실제로 들고 있을 때 진동이 줄면 좋아지는 진행도를 추가하고, PPO/A2C는 tanh 행동·보정된 로그 확률·작은 초기 탐색·학습률로 변경했다. 성공 임계값은 유지한다.

장시간 실행 전 별도 시험에서 PPO의 초기 성공 후 성능 하락과 드문 유지 타이머의 정규화 포화를 확인했다. PPO의 학습률·클리핑·KL·에포크를 보수적으로 조정하고, 범위가 정해진 작업 상태는 센서 정규화와 분리했다. 이는 수렴 보장이 아니며 모델별 검증 최고 정책을 따로 보존한다.

1단계 최고 정책은 성공률·안정된 들기율·실제 잡기율·총보상 순으로 선택한다. 성공 전에는 잡기 진척이 있어도 단순 총보상이 낮을 수 있으므로 정지한 정책을 계속 보관하지 않게 했다. 본학습 검증 간격은 25,600스텝이다.

새 PPO·A2C·SAC는 `runs/studies/three_models_1kg_v3/`에서 모델별 독립 환경과 독립 난이도로 1단계부터 각각 2천만 스텝을 학습한다. 이전 모델은 이어받지 않는다. 실시간 화면·상위 10개·그래프는 기존 웹 주소에서 모델별로 확인한다. 반복 학습 로그는 채팅으로 보내지 않는다.
