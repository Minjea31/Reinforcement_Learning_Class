# 두 팔 로봇 운반 시뮬레이터

MuJoCo와 Gymnasium으로 만든 3D 로봇 시뮬레이터입니다. 두 로봇 팔과 집게로 물체를 잡아 장애물을 피해 목표 위치에 옮기는 강화학습 실험용 환경입니다.

- 팔마다 구면 관절 2개와 집게 1개를 사용합니다.
- 물체의 시작점·목표점과 장애물의 위치·크기를 무작위로 생성합니다.
- 중력, 질량, 마찰, 충돌을 적용하며 물체 무게를 조절할 수 있습니다.
- 현재는 수동 조작이 가능하며, 협동 운반이나 물체 인계 방식은 이후 학습할 예정입니다.

## 실행 방법

프로젝트 폴더에서 실행합니다. `.venv` 가상환경에 `requirements.txt`의 패키지가 설치되어 있어야 합니다. 현재 작업 환경에는 설치되어 있습니다.

```bash
./run_simulator.sh
```

배치를 재현할 시드와 물체 무게(kg)를 지정할 수도 있습니다.

```bash
./run_simulator.sh --seed 31 --mass 1.0
```

## 기본 조작

- **New task / N**: 새로운 랜덤 배치 생성
- **Reset / R**: 현재 시드의 초기 배치로 복원
- **Pause / Space**: 일시정지·재개
- **Manual joints 탭**: 관절과 집게 수동 조작
- **3D 화면**: 마우스 드래그로 회전, 휠로 확대·축소

왼쪽 조작 창에서 물체 무게를 바꾸고 관절 토크와 접촉 상태를 확인할 수 있습니다.
