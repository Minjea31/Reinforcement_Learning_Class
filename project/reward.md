# 새 교육과정의 단계별 보상함수

2026-11-27 수정 v4. 물체 1kg, PyTorch PPO·A2C·SAC의 독립 모델, 행동 한 스텝 0.02초를 기준으로 설계했다.

**새 PPO·A2C·SAC 실행의 기본 progressive 모드에 적용했다.** 계산 모듈은 [simulation/reward_design.py](simulation/reward_design.py), 환경 연결과 가까운 거리부터 시작하는 초기화는 [simulation/study_curriculum.py](simulation/study_curriculum.py)에 있다. 기존 native 실행기의 보상은 [reward_current.md](reward_current.md), 배치와 물리 검토는 [curriculum_review.md](curriculum_review.md)에 있다. 계수·속도 임계값은 실험 시작값이며 PPO·A2C·SAC 수렴을 보장하지 않는다.

## 1. 공통 구조

```text
r = 0.999 × Φ_next − Φ_before
    + 성공 − 낙하 − 충돌 − 시간 − 위험한 잡기 손실 − 4단계 힘 비용
```

`Φ`는 상태의 작업 진행도다. **진행도 자체를 매 스텝 지급하지 않고, 개선되는 정도를 보상한다.** 진행도 10인 상태에 계속 머무르면 shaping은 `0.999×10−10=−0.01`이다. 가까이 갔다가 돌아오는 행동도 반대 방향의 변화로 정산된다. 전체 상태가 같은 닫힌 경로에서 할인된 shaping의 합은 `(gamma^T−1)×Φ_start`다.

| 항목 | 지급 방식 | 적용 단계 |
|---|---|---|
| 성공 | 한 번 `+100`, 종료 | 1~4 |
| 낙하 | 물체 중심 z<0.48m일 때 `−25`, 종료 | 1~4 |
| 충돌 | `−0.5×dt×min(5, 장애물 접촉 수+좌우 팔 사이 접촉 수)` | 1~4 |
| 시간 | `−0.2×dt` | 1~4 |
| 위험한 잡기 손실 | 사건마다 `−2` | 2~4 |
| 토크·집게 힘·두 팔 사용 | 아래 4단계 식 | 4만 |

기본 dt=0.02이므로 시간 비용은 스텝당 −0.004, 시뮬레이션 1초당 −0.2다. 정상적인 집게·물체 접촉과 물체·테이블 접촉 자체는 충돌 비용에 넣지 않는다. 충돌 접촉점 상한 5는 접촉점이 많이 생기는 상황에서 비용이 과도하게 커지는 것을 제한한다.

성공·낙하로 종료하면 `Φ_next=0`으로 정산한다. 따라서 마지막 스텝 보상이나 성공 에피소드 총보상이 정확히 100인 것은 아니다. 시간 제한만 도달한 경우에는 마지막 물리 상태의 진행도를 유지하고 PPO가 해당 상태 가치를 부트스트랩한다. 별도 시간 초과 벌점은 두지 않는다.

## 2. 공통 측정값

물리 상태를 측정하며, 집게를 닫는 명령만으로 잡기 보상을 주지 않는다.

- **실제 잡기:** 한 팔의 두 패드 모두 물체에 접촉하고 각 패드의 법선 접촉력이 0.5N 초과. 연속 0.1초 유지하면 안정된 잡기다.
- **h:** 물체 바닥 높이−테이블 높이(0.60m). 물체 회전을 반영한 수직 투영으로 바닥을 구한다.
- **d_i:** 각 집게 중심에서 물체의 유효한 잡기 후보 지점까지의 최소 거리. 현재 길이 18cm 물체에서는 로컬 x방향 −5.5cm·0·+5.5cm 지점을 물체의 회전·위치로 변환한다. 후보의 안전성은 배치별 물리 시험으로 확인해야 한다.
- **a_i:** 집게가 닫히는 축과 물체 폭 방향의 단위벡터 내적 절댓값. 0은 직각, 1은 정렬이다.
- **목표 포함:** 물체 수평 투영 전체가 목표 안에 들어오는지 확인한다. 현재와 같은 판정 여유 2mm를 사용한다.
- **속도:** 선속도(m/s)와 각속도(rad/s)를 각각 측정한다. 단위가 다른 값을 하나의 노름으로 섞지 않는다.

집게가 물체 중심 외의 지점도 사용할 수 있게 해, 양팔이 같은 중심점으로 몰릴 필요를 줄인다. 이 지점은 보상 측정 기준이며 사용할 팔이나 행동을 지정하는 명령은 아니다.

## 3. 1단계: 접근·잡기·들기·유지

물체는 테이블 위, 집게는 열린 상태로 시작한다. 목표까지 운반하는 점수는 없다.

```text
clip(x) = x를 0~1로 제한

A_i = 10 × (1 − clip(d_i / 0.80m))
Z_i =  2 × (1 − clip(d_i / 0.15m)) × a_i
접근·정렬 = max_i(A_i + Z_i)

g = clip(현재 잡고 있는 팔의 최대 연속 잡기 시간 / 0.1초)
잡기 = 5 × g
들기 = 15 × clip(h / 0.06m) × g
q = 1 / (1 + (선속도 / 0.1m/s)^2 + (각속도 / 0.5rad/s)^2)
안정화 = 4 × clip(h / 0.03m) × g × q  (테이블 지지가 없을 때, 그 외 0)
유지 = 4 × clip(유효한 들기 조건의 연속 유지 시간 / 0.5초)

Φ_1 = 접근·정렬 + 잡기 + 들기 + 안정화 + 유지
```

접근 점수는 80cm 안에서 선형으로 증가한다. 먼 거리에서도 작은 접근에 대한 신호를 주려는 목적이다. 80cm 이상에서는 포화되므로 적어도 한 팔의 초기 유효 접근 거리를 그 안으로 제한해야 한다. 정렬 점수는 물체 15cm 안에서만 생기고, 거리와 방향은 동일한 팔의 값을 함께 평가한다.

잡기 점수는 실제 접촉이 이어질 때 생긴다. 들기 점수는 실제 잡기가 있을 때만 증가하므로 잡지 않고 튕겨 올리는 상태에는 주지 않는다. 유지 타이머는 유효 조건이 깨지면 0으로 돌아간다. 힘과 두 팔 사용 비용은 0이다.

v4의 안정화는 엄격한 성공 속도에 아직 못 미쳐도 진동이 줄면 진행도가 높아지는 신호다. 실제 잡기·높이·테이블 지지 해제가 필요하고 최대 4이며, 매 스텝 지급하는 보너스가 아닌 같은 potential 차분에 포함된다. 2~4단계에서 들기 자격을 얻기 전에도 적용한다. 잡고 들기 진행도의 최대값은 유지 제외 36, 유지 포함 40이다.

**성공 조건:** 적어도 한 팔의 안정된 잡기, 바닥 3cm 이상 들기, 테이블 지지 없음, 물체 선속도≤0.1m/s·각속도≤0.5rad/s를 연속 0.5초 만족한다. 첫 실험의 성공 기준을 그대로 유지했다.

관측은 105차원을 유지한다. 인덱스 82는 현재 유효 들기 시간/0.5초(최대 1), 87은 이 보상에서의 들기 자격, 88은 1단계 유효 들기 시간 또는 2~4단계 유효 안착 시간이다. 모두 이번 물리 스텝의 판정 후 반환한다. 98번의 중복 높이 값은 운반 진행도 계산에 필요한 에피소드 초기 목표 거리로 바꿨다. 물체 높이는 qpos에 그대로 있다. 이전 보상 타이머와 관측에 없는 초기 거리로 새 보상을 예측하게 하던 불일치를 제거했다.

신경망에 입력할 때 82~88번의 타이머·잡기·사용 이력·들기 자격과 98번의 초기 거리, 마지막 6개의 단계 문맥은 원래 값을 유지한다. 드문 사건의 작은 분산 때문에 서로 다른 유지 시간이 같은 정규화 상한으로 잘리지 않게 한다. 나머지 센서는 실행 중 통계로 정규화한다. 이 전처리의 버전은 체크포인트에 기록하며 이전 전처리로 저장된 모델을 새 설정에서 재개하지 않는다.

계산 예시: 잡기·정렬·들기 변화 없이 집게가 물체에서 50cm→40cm로 접근하면:

```text
Φ_before = 10 × (1−0.50/0.80) = 3.75
Φ_next   = 10 × (1−0.40/0.80) = 5.00
shaping  = 0.999×5−3.75 = +1.245
시간 비용을 포함한 보상 = +1.241
```

한 스텝에 반드시 10cm 움직일 수 있다는 뜻은 아니며 수식 계산용 예시다. 실제 작은 이동에도 같은 식을 적용한다.

| 거리 | 기존 `10×(1−tanh(5d))` | 새 접근 점수 |
|---|---:|---:|
| 70cm | 0.018 | 1.25 |
| 60cm | 0.049 | 2.50 |
| 50cm | 0.134 | 3.75 |
| 40cm | 0.360 | 5.00 |
| 30cm | 0.949 | 6.25 |

위 비교는 중심과 잡기 후보 지점이라는 거리 기준 차이를 제외하고 수식만 비교했다. 먼 거리의 점수 변화가 커지지만, 도달 불가능한 배치나 탐색 실패까지 해결하는 것은 아니다. 가까운 초기 자세부터 범위를 넓히는 교육과정이 함께 필요하다.

## 4. 2단계: 운반·내려놓기·놓기

1단계 정책이 실제로 잡고 든 상태를 이어받는다. 준비 과정의 스텝·보상·힘은 새 에피소드에 포함하지 않는다.

들기 자격이 있는 동안:

```text
D = max(0.25m, 에피소드 시작 물체~목표의 수평 거리)
p = clip(1 − 현재 물체~목표의 수평 거리 / D)
w = 1 − clip(현재 물체~목표의 수평 거리 / 0.10m)
b = 1 − clip(max(0,h) / 0.10m)
r = 목표 전체 포함 + 테이블 지지 + 로봇 접촉 없음이면 1
s = clip(연속 안착 조건 유지 시간 / 1초)

Φ_2 = 36 + 25×p + 12×w×b + 5×r + 8×s
```

| 항목 | 의도 |
|---|---|
| 36 | 실제 잡고 든 자격을 유지한다. 목표에 정상적으로 놓을 때 잡기를 풀었다고 이 점수가 사라지지 않는다. |
| 25×p | 목표까지의 수평 거리를 줄인다. |
| 12×w×b | 목표 10cm 안에서만 낮추는 동작을 유도한다. 먼 곳에서 낮추면 이 항목은 0이다. |
| 5×r | 목표 안에서 테이블에 놓고 실제 로봇 접촉을 해제하도록 한다. 열기 명령만으로는 주지 않는다. |
| 8×s | 놓은 물체의 안정적인 유지 시간을 늘린다. |

각 항목은 진행도이며 매 스텝 그대로 받는 보너스가 아니다. 목표에서 초기 거리보다 더 멀어지면 p=0이라 운반 신호가 평평해지는 한계가 있다.

들기 자격은 안정된 실제 잡기와 3cm 이상 들기를 연속 0.2초 확인한 뒤 설정한다. 목표 안에 정상적으로 놓는 동안에는 유지한다. 목표 밖 테이블에 다시 놓으면 자격을 해제하고, 다시 들기 전에는 1단계 접근·정렬·잡기·들기 식(유지 항목 제외)을 사용한다.

**잡기 손실 −2:** 이전에 들기 자격과 안정된 잡기가 있었는데 다음 상태에서 어느 팔도 잡지 않으면 검사한다. 목표 안·테이블 지지·선속도≤0.1m/s·각속도≤0.5rad/s인 안전한 내려놓기가 아니면 비용을 준다. 목표 위라도 공중에서 놓으면 해당할 수 있다. 다른 팔이 계속 잡고 있으면 비용은 없다.

**성공 조건:** 아래를 연속 1초 만족한다.

- 실제로 들어 올린 자격이 있다.
- 목표 중심과의 수평 거리 4cm 미만이며 물체 수평 투영 전체가 목표 안에 들어온다.
- 테이블 지지 접촉이 있고, 법선력 0.1N 초과의 로봇·물체 접촉점이 없다.
- 어느 팔도 물체를 잡고 있지 않다.
- 선속도<0.03m/s, 각속도<0.15rad/s.

계산 예시: 초기 거리 40cm에서 목표 20cm 앞까지 옮기면 p=0.5다. 여전히 높이 들고 있으면 진행도는 `36+25×0.5=48.5`다. 목표 2cm 앞, 물체 바닥 높이 2cm에서는 w=b=0.8이므로 내려놓기 진행도는 `12×0.8×0.8=7.68`이다. 실제 지급액은 매 스텝 할인과 다른 비용을 반영한다.

## 5. 3단계: 전체 작업·장애물·전달

다시 잡지 않은 상태부터 시작한다.

```text
들기 자격 전: Φ_3 = 접근·정렬 + 잡기 + 들기
들기 자격 후: Φ_3 = 2단계의 36 + 운반 + 낮추기 + 접촉 해제 + 안정화
```

목표에 놓기까지 완료해야 성공 +100을 준다. 잡고 드는 것만으로는 이 단계의 성공이 아니다. 힘·두 팔 사용 비용은 0이다.

- 한 팔로 끝내도 성공한다.
- 전달 중 다른 팔이 잡고 있으면 보내는 팔이 놓아도 잡기 손실 비용은 없다. 좌우 역할을 고정하지 않는다.
- 양팔 지지도 허용하지만 두 팔 사용 자체에 별도 보너스는 없다.
- 장애물 접촉 비용은 유지한다. 이 비용만으로 모든 경로의 안전과 해결 가능성이 보장되지는 않는다.

전달 보너스를 따로 주면 한 팔로 가능한 배치에서도 불필요하게 넘길 수 있어 기본 식에는 넣지 않는다. 다만 이 식은 받는 팔 접근에 직접적인 추가 점수를 주지 않아 전달 탐색이 어려울 수 있다. 먼저 쉬운 배치에서 물리적 전달을 완주시키고 좁은 분포에서 학습한 뒤 범위를 넓혀야 한다. **현재 실제 양팔 전달의 완전한 성공은 아직 확인하지 못했다.**

## 6. 4단계: 성공 유지·최소 힘

3단계의 진행도·성공 조건을 유지하면서 비용을 추가한다.

```text
T = 이번 행동 구간의 ∫ mean(12축 실제 토크 절댓값)/65Nm dt
F = 이번 행동 구간의 ∫ mean(두 집게의 실제 액추에이터 힘 절댓값)/200N dt
B = 에피소드에서 두 팔의 안정된 잡기 이력이 처음 모두 완성되면 1

힘·팔 비용 = −α × (0.5×T + 0.05×F + 2×B)
```

난이도 0~4에서 α를 **0 → 0.25 → 0.5 → 0.75 → 1**로 올린다. T와 F는 물리 스텝 0.002초마다 계산하여 행동 구간에 합한다. 정지해 있어도 물체 무게를 버티는 실제 모터 토크가 포함된다. 힘을 0으로 만들라는 뜻이 아니라 성공에 필요한 힘은 사용하면서 불필요한 사용을 줄이는 것이다. 이 적분은 전력량·에너지 자체는 아니다.

두 팔 비용은 에피소드당 한 번이며 순차 전달도 포함한다. 양팔을 금지하거나 위치에 따라 팔을 지정하지 않는다. 가중합은 한 팔에 대한 선호이고 모든 상황에서 한 팔 사용을 수학적으로 강제하지는 않는다.

새 계수 0.5·0.05·2는 실험 시작값이다. 현재 실행은 여전히 0.1·0.025·10을 사용한다. 힘 비용 때문에 성공률이 하락하면 강도 증가를 보류하거나 낮춰야 한다. 성공 보너스 100이 모든 긴 궤적에서 성공을 항상 더 높은 반환으로 만든다고 보장할 수는 없다.

계산 예시: 10초 동안 12축 전체의 평균 절대 토크가 20Nm, 두 집게 평균 절대 힘이 50N이었다면 α=1에서:

```text
T 누적 = (20/65)×10 = 약 3.077 → 비용 약 −1.538
F 누적 = (50/200)×10 = 2.5    → 비용 −0.125
양팔 모두 사용했다면 추가 −2
```

한 모터만 20Nm라는 뜻이 아니라 12축 평균값을 가정한 예시다. 위는 할인 전 비용 합이며 시간·충돌·진행도·성공은 별도로 합산한다.

## 7. 난이도와 평가

1~3단계는 난이도가 올라가도 보상 계수를 유지하고 초기 거리·자세·장애물·전달 배치를 바꾼다. 4단계에서만 힘 비용 강도 α를 올린다. 구체적인 배치·승급 계획은 [curriculum_review.md](curriculum_review.md)에 있다.

| 단계 | 별도로 기록할 지표 |
|---|---|
| 1 | 초기·최소·최종 손~잡기 지점 거리, 실제 잡기율·들기율·안정 유지 성공률 |
| 2 | 목표 거리 감소, 목표 도달률·접촉 해제율·최종 안착률 |
| 3 | 한 팔·장애물·전달 시나리오별 성공률, 실제 전달 완료 사례 |
| 4 | 성공률, 성공 에피소드의 힘 사용량·팔 수·소요 시간 |

모델 선택은 성공률을 우선하고 한 팔 사용·힘 사용도 비교한다. 서로 다른 초기 상태·단계의 누적 보상은 직접 비교하지 않는다. 보상이 올라도 잡기·들기·안착이 늘지 않으면 과제 학습의 증거로 보지 않는다.

## 8. 계산 모듈 사용과 적용 범위

```python
from simulation.reward_design import RewardState, compute_reward

before = RewardState(hand_distances=(0.50, 0.90))
after = RewardState(hand_distances=(0.40, 0.90))
result = compute_reward(before, after, stage=1)
print(result.total)  # 약 1.241
print(result.terms)
```

계산 모듈은 상태를 수정하거나 행동을 생성하지 않는다. 새 환경은 아래 규칙으로 연결했다.

1. 실제 MuJoCo 집게·물체 회전·접촉·속도에서 RewardState를 만든다. Boolean은 명령이나 예측이 아닌 물리 상태로 채운다.
2. 잡기·들기·안착 연속 타이머와 사용 팔 이력을 갱신한다. `lift_condition`·`placement_condition`이 깨지면 해당 유지 타이머를 0으로 되돌린다. 에피소드 안의 사용 팔 이력은 지우지 않는다.
3. 물리적인 들기 자격과 목표 밖 재접촉을 관리한다. 2단계의 첫 before는 준비가 끝난 실제 상태에서 만든다.
4. 힘 적분은 이번 행동 구간 값만 넣는다. 에피소드 누적값을 매번 넣으면 중복 차감된다.
5. 성공·낙하 terminated와 시간 제한 truncated를 구분하고 보상 버전을 체크포인트·웹 비교에 기록한다.

수식 테스트와 새 환경의 재현·독립 승급·물리적 잡기/들기 테스트를 수행했다. 새 실행은 1단계부터 모델별로 난이도를 올린다. 후속 단계의 전달 시나리오 완주는 아직 확인하지 못했으며, 세 모델의 장기 학습 성공 역시 초기 실행 시험만으로 단정하지 않는다.
