# 현재 구현의 단계별 보상함수

기존 native PPO 실행기의 호환용 보상 설명이다. 새 PPO·A2C·SAC 비교 실행은 [reward.md](reward.md)의 v4 보상을 사용한다.

현재 커리큘럼 코드 기준이다. 물체는 모든 단계에서 **1kg**이며 같은 PPO 모델을 이어서 사용한다.

`--physics-backend warp`에서도 아래 보상식·계수·성공 임계값은 동일하다. 물리와 모터 제어는 GPU에서 계산하고 관측·보상 판정은 CPU에서 수행한다. 2단계 시작 상태를 만드는 고정된 1단계 정책의 준비 과정은 CPU에서 실행하며, 그 스텝·보상은 2단계 학습에 포함하지 않는다. 백엔드별 접촉 계산의 수치 차이는 있을 수 있다.

- **기존 버전(v1)**: `--task-version`을 생략하거나 `1`로 지정. 기존 체크포인트는 이 버전으로 실행된다.
- **수정 버전(v2)**: `--task-version 2`. 2단계를 1단계 정책이 실제로 잡고 들어 올린 상태에서 시작하며, 운반·내려놓기 보상과 판정을 수정했다.

## 1. 매 스텝 보상의 구성

```text
reward = shaping + success + fall + collision + time
         + torque + gripper + second_arm + premature_release

shaping = gamma × Φ(다음 상태) − Φ(이전 상태)
```

`Φ`는 아래에서 설명하는 진행도 점수다. 잡기 점수 5는 매 스텝 +5를 지급한다는 의미가 아니다. 점수가 개선된 정도를 보상한다. 기본 `gamma=0.999`, 행동 한 스텝은 시뮬레이션 시간 **0.02초**다.

| 항목 (`reward_terms`) | 실제 보상 | 적용 단계 |
|---|---|---|
| `shaping` | `0.999 × Φ_next − Φ_prev` | 1~4 |
| `success` | 성공 시 한 번 **+100** | 1~4 |
| `fall` | 물체 중심 높이 `z < 0.48m`이면 **−25**, 종료 | 1~4 |
| `collision` | `−0.5 × 0.02 × (장애물 접촉 수 + 좌우 팔 사이 접촉 수)` | 1~4 |
| `time` | 스텝당 **−0.004**, 시뮬레이션 1초당 −0.2 | 1~4 |
| `torque` | `−0.1 × effort_scale × torque_integral` | 4 |
| `gripper` | `−0.025 × effort_scale × gripper_integral` | 4 |
| `second_arm` | 에피소드에서 두 팔 모두 안정적으로 잡은 이력이 처음 완성되면 `−10 × effort_scale` | 4 |
| `premature_release` | 목표 밖에서 안정된 잡기를 잃은 순간 **−2** | v2의 2~4 |

접촉 수는 현재 MuJoCo 접촉점 개수다. 장애물·팔 충돌만 직접 비용을 주며 테이블에 정상적으로 물체를 놓는 접촉 자체는 충돌 비용이 아니다.

**성공·낙하로 종료하는 스텝은 `Φ_next=0`으로 계산한다.** 따라서 마지막 스텝 보상은 성공해도 정확히 +100이 아니며, 이전 진행도 점수와 비용을 함께 반영한다. 시간 제한 종료에는 이 처리를 하지 않고 PPO가 마지막 상태 가치를 부트스트랩한다. 기본 단계별 제한은 600·1200·2000·2000스텝이며 `--max-steps`가 더 작으면 그 값을 쓴다.

## 2. 1단계: 잡고 들어 유지하기 · v1/v2 공통

```text
g = min(1, 한 팔의 최대 연속 잡기 시간 / 0.1초)
h = 물체 바닥 높이 − 테이블 높이(0.60m)
d_hand = 두 집게 중 물체 중심까지 더 가까운 집게의 거리

접근     = 10 × (1 − tanh(5 × d_hand))
잡기     =  5 × g
들기     = 15 × clip(h / 0.12m, 0, 1) × g
유지     =  4 × min(1, 연속 성공 조건 유지 시간 / 0.5초)

Φ = 접근 + 잡기 + 들기 + 유지
```

물체 가까이 접근하고, 실제 양쪽 집게 패드로 잡고, 들어 유지하도록 유도한다. 힘 비용과 두 번째 팔 비용은 **0**이다.

성공하려면 안정된 잡기 0.1초 이상을 유지하면서 물체 바닥을 테이블 위 **3cm 이상** 들어 올린 상태를 **0.2초** 유지해 운반 자격(`carried`)을 얻어야 한다. 이어서 테이블 지지 없이 잡고 있는 성공 조건을 **0.5초** 유지하면 +100을 받고 종료한다. 패드 접촉은 각 패드의 수직 접촉력이 0.5N을 초과해야 잡기로 인정한다.

`--layout-mode random_all`에서는 1단계부터 시작점·목표점을 매번 바꾼다. 같은 한 팔이 두 지점과 중간 운반 경유점에 닿는 범위에서 뽑고 표시 영역이 겹치지 않게 검사한다. 열린 집게의 초기 대기 자세도 시작점에 맞춘다. 목표가 랜덤이어도 1단계 보상에는 운반 항목을 추가하지 않으며, 목표까지 이동·놓기는 2단계에서 학습한다. 리셋의 도달 범위 검사는 행동 중 제어나 자동 운반이 아니다.

`--layout-mode random_approach`에서는 같은 물체 배치에 두 팔의 초기 관절 자세도 별도로 랜덤 샘플링한다. 두 집게를 완전히 열고 물체와 최소 거리를 두며 관절 한계·작업 범위·충돌을 검사한다. 보상식과 1단계 성공 조건은 동일하고, 접근 점수가 멀리서 물체에 다가가는 행동을 유도한다. 초기 진행도 점수가 달라지므로 이전 초기화 방식의 누적 보상과 직접 비교하지 않는다.

| 난도 | 두 집게 모두의 최소 거리 | 물체에 닿을 수 있는 팔의 최대 시작 거리 |
|---|---:|---:|
| 0 | 15cm | 55cm |
| 1 | 16.25cm | 60cm |
| 2 | 17.5cm | 65cm |
| 3 | 18.75cm | 70cm |
| 4 | 20cm | 75cm |

거리는 집게와 물체 중심의 3차원 거리다. 관절 샘플링 폭도 난도와 함께 늘린다. 기존 방식의 물체 위 0.5~8cm 초기 위치와 손가락 벌림 증가 대신 이 거리 범위를 사용하며, 집게는 모든 난도에서 완전히 열린다. 2단계 준비용 1단계 정책에도 같은 랜덤 팔 자세를 적용하되, 2단계 본학습은 실제로 잡고 든 상태를 이어받는다. 3·4단계도 랜덤 팔 자세로 접근부터 학습한다.

## 3. 2단계: 옮기고 내려놓기 · 수정 버전 v2

시작 전 고정된 1단계 정책으로 물체를 들어 올린다. 잡은 상태에서 진동이 잦아들면 위치·속도·관절 목표·잡기 이력을 그대로 이어받는다. 준비 과정은 2단계의 스텝·보상·힘 사용 누적에 포함하지 않는다. 이후 이동과 집게 제어는 학습 중인 정책이 결정한다.

목표의 수평 이동 거리는 난도별로 **0 → 6 → 12 → 18 → 25cm**다. 첫 난도는 바로 아래 내려놓기부터 배운다.

위 거리는 기본 `--layout-mode fixed` 설정이다. `--layout-mode random_separated`를 선택하면 준비용 정책이 실제로 잡을 수 있는 범위에서 시작 위치를 바꾸고, 목표는 독립적으로 추출한다. 시작·목표 영역이 겹치지 않도록 2.5cm 이상의 여유와 중심 거리 최소 22cm를 요구하며, 허용 최대 거리는 난도에 따라 38~50cm다. 보상식은 그대로 유지하고 `D`에는 해당 에피소드의 실제 초기 거리를 사용한다. 기존 모델·Adam·관측 정규화를 이어받지만 배치가 바뀌므로 새 실행 폴더에서 난도와 검증 기준을 다시 시작한다. 진행 중인 프로세스에는 자동 적용되지 않는다.

운반 자격이 있는 동안:

```text
D = max(0.04m, 에피소드 시작 시 물체와 목표의 수평 거리)
d_xy = 현재 물체 중심과 목표의 수평 거리
p = clip(1 − d_xy / D, 0, 1)
h = max(0, 물체 바닥 높이 − 0.60m)
l = clip(1 − h / 0.12m, 0, 1)
q = min(1, 연속 안착 조건 유지 시간 / 1초)

Φ = 30 + 25 × p + 15 × p × l + 10 × q
```

| 부분 | 의미 |
|---|---|
| `30` | 이미 잡고 든 진행도를 유지한다. 목표 안에서 집게를 열어도 이 점수가 사라지지 않는다. |
| `25 × p` | 목표와의 수평 거리를 줄이도록 한다. |
| `15 × p × l` | 목표 가까이에서 테이블 쪽으로 낮추도록 한다. |
| `10 × q` | 놓은 물체가 안정적으로 유지되도록 한다. |

운반 자격이 없으면 1단계의 **접근 + 잡기 + 들기** 식을 사용한다(유지 항목 제외). 목표 밖 테이블에 다시 놓으면 운반 자격이 해제되므로 다시 들어야 한다.

추가 비용 −2는 이전 스텝에 운반 자격과 안정된 잡기(0.1초)가 있었고, 이번 스텝에 어느 팔도 잡고 있지 않으며 물체 전체가 목표 영역 안에 있지 않을 때 적용한다. 열기 명령 자체를 금지하지 않으며 다른 팔이 계속 잡고 있으면 이 비용은 없다. 잡기를 다시 얻었다가 또 잃으면 다시 적용될 수 있다.

성공은 운반 자격을 유지하면서 아래 조건을 **연속 1초** 만족하는 것이다.

- 물체 중심과 목표의 수평 거리 **4cm 미만**.
- 물체의 수평 투영 전체가 목표 영역 안에 들어옴(판정 여유 2mm).
- 테이블이 물체를 지지함(접촉력 0.1N 초과).
- 로봇과 물체 사이의 수직 접촉력이 0.1N을 초과하는 접촉점이 없음.
- 물체 자유 관절의 선속도 3개·각속도 3개를 합친 6차원 벡터의 노름이 **0.08 미만**. 단순한 선속도 0.08m/s 기준은 아님.

똑바로 세우는 자세 조건은 없다. 힘·두 번째 팔 사용 비용은 아직 0이다.

## 4. 3단계: 랜덤 시나리오로 확대

**v2는 2단계와 같은 진행도 식·조기 잡기 손실 비용·안착 성공 조건**을 사용한다. 2단계의 고정 정책 준비 과정은 사용하지 않고 물체를 다시 잡는 것부터 학습한다. 시작점·목표점·장애물 배치의 무작위성을 난도에 따라 늘린다.

난도 `0, 0.25, 0.5, 0.75, 1`에 따라 랜덤 배치를 뽑을 확률이 늘어난다. 랜덤 배치 안에서도 같은 난도 확률로 장애물을 유지하며, 그 외에는 장애물을 작업 영역 밖으로 옮긴다. 난도 1에서는 전체 랜덤 배치와 장애물을 사용한다. 보상 계수는 난도에 따라 바뀌지 않으며 힘·두 번째 팔 비용은 0이다.

`random_all` 모드에서는 3·4단계의 첫 난도부터 시작점·목표점·장애물 위치와 크기를 매번 새로 뽑는다. 기존 모드의 랜덤 확률 증가 대신 전체 랜덤 배치를 사용하며, 보상식과 4단계의 힘 비용 증가는 그대로 유지한다.

## 5. 4단계: 성공을 유지하며 힘과 팔 사용 줄이기

전체 랜덤 배치에서 운반 성공을 계속 학습한다. v2 진행도 식·안착 판정은 2~3단계와 같다. 추가로 `effort_scale = 0 → 0.25 → 0.5 → 0.75 → 1`로 다음 비용을 강화한다.

```text
torque_integral  = ∫ mean(12개 관절 축의 실제 토크 절댓값) / 65Nm dt
gripper_integral = ∫ mean(두 집게의 실제 액추에이터 힘 절댓값) / 200N dt

토크 비용 = −0.1   × effort_scale × torque_integral
집게 비용 = −0.025 × effort_scale × gripper_integral
두 팔 비용 = −10   × effort_scale  (두 팔의 잡기 이력이 처음 모두 채워질 때)
```

적분은 매 물리 스텝(0.002초)에서 계산해 한 행동 구간(0.02초) 동안 합한다. 움직임이 없어도 물체를 버티는 모터 힘은 비용에 포함된다. 이 값은 **토크·힘 사용량 지표**이며 전력량·기계적 에너지 자체가 아니다.

두 팔 비용은 동시 잡기만 보는 것이 아니다. 왼팔로 잡았다가 오른팔로 넘겨도 에피소드 안에서 양쪽 팔이 각각 0.1초 이상 잡은 이력이 생기면 적용된다. 두 팔을 금지하는 규칙은 없고, 한 팔로 성공 가능한 경우에는 비용이 적은 행동을 배우도록 유도한다. 협동·넘겨주기 자체에 별도 양의 보상은 없다.

로그의 `episode_effort`는 `torque_integral + 0.25 × gripper_integral`을 에피소드 동안 합한 값이다. 실제 비용은 여기에 `−0.1 × effort_scale`을 곱한 것과 같다.

## 6. 기존 버전 v1과 다른 점

v1의 1단계는 위와 같고, 2~4단계 진행도는 다음 식이다.

```text
운반 = carried이면 20 × (1 − min(1, 물체와 목표의 3차원 거리 / 1.4m))
       carried가 아니면 0
유지 = 4 × min(1, 연속 성공 조건 유지 시간 / 1초)

Φ = 접근 + 잡기 + 들기 + 운반 + 유지
```

v1의 2단계는 잡기 전 상태에서 시작하며 목표 거리는 12~25cm다. 집게를 놓으면 잡기·들기 점수가 줄어들 수 있고, 별도의 −2 잡기 손실 비용은 없다. 2~4단계 성공에는 3차원 목표 거리 4cm 미만, 기울기 12도 미만, 테이블 지지, 목표 영역 포함, 패드 접촉 해제, 위의 6차원 속도 노름 0.08 미만과 운반 자격·1초 유지가 필요하다. v2는 수평 거리·전체 로봇 접촉 해제 판정을 사용하고 기울기 제한을 없앴다. 4단계 힘·두 팔 비용의 식은 동일하다.

## 7. 누적 보상과 평가 지표를 읽는 방법

에피소드 누적 보상은 매 스텝 `reward`의 단순 합이며, PPO는 할인된 미래 보상을 학습한다. 성공 보너스 +100은 에피소드 누적 보상의 고정 최대값이 아니다. 초기 진행도, 종료 시 진행도 정산, 소요 시간·충돌·힘 비용에 따라 성공한 보상도 달라진다. 특히 잡고 든 상태에서 시작하는 v2 2단계는 초기 `Φ`가 이미 높다.

목표 도달률·접촉 해제율·안착률·이동 진척도는 평가 통계다. 별도의 즉시 보상으로 매번 더하지 않는다. v2의 2~3단계 최고 모델은 **성공률 → 안착률 → 목표 안 접촉 해제율 → 목표 도달률 → 평균 이동 진척도 → 평균 보상** 순으로 비교한다. 4단계는 **성공률 → 성공 시 적은 팔 수 → 성공 시 적은 힘 사용량 → 평균 보상** 순이다. 이 모델 선택 기준과 PPO의 스텝 보상은 서로 다르다.
